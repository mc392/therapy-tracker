3. Beta terms — please read before adding real client data

  • Back up before and during testing. Use Settings → Backups to export a copy regularly. Don't rely on the app as your only record.
  • Use one device at a time. The app does not currently coordinate between multiple open tabs or multiple devices. If the same data is edited in two places, whichever saves last silently overwrites the other — there is no merge and no warning. Keep to a single active device/tab per dataset until this is addressed.
  • Data formats may change. As a beta product, upgrades may change how data is stored. We aim to migrate your existing data automatically, but you should still hold an independent backup.
  • Report problems. If something looks wrong — a missing session, an incorrect total — stop, export a backup of the current state, and get in touch before continuing, so we can investigate what happened.
